# cmark

This vendored CommonMark parser is built as a static C99 library for the
launcher. It provides CommonMark parsing and HTML, XML, LaTeX, man-page, and
CommonMark renderers. Only the library target is retained; the command-line
program, developer tooling, package metadata, wrappers, and separate install
flows are not part of this project.

The upstream source and licence are preserved in this directory.
