# XLuke44's Prism Launcher

This is my own fork of Prism Launcher 8.4. I originally made it for personal use, but decided to share it with everyone.

The goal of this fork is to make Prism Launcher lighter, reduce unnecessary overhead, and introduce various quality-of-life improvements. 
I also want to keep things as local as possible. Translations work entirely offline, so there's no need for an internet connection. All instances also start offline by default.

Microsoft account login is optional, so you can use the launcher without signing in. I've also made my own default theme, while keeping the original Prism Launcher themes available.

This is a personal project, so development happens at my own pace and according to my own priorities.

Anyway, enjoy everyone ^w^ Have a great day/night

## Online Mode Warning

First launch of any instance with minecraft version or modloader version that hasn't been installed before will start in online mode.

## Supported Operating systems

This Fork Supports Only Windows and Linux. **There are no plans to support other operating systems.**

## Release Format

* Linux portable releases are built using scripts/build-linux-portable.bash.
* Windows portable releases are built using scripts/build-windows-portable.bash.

## APIs

This fork currently relies on Prism Launcher's Microsoft Application ID, as I have been unable to obtain one of my own. It will remain in use for the foreseeable future until I can secure a reliable replacement.

Starting with version 1.0.5.0, this fork uses its own CurseForge Core API key. Imgur support has also been removed entirely, along with all related code and API key configuration.
