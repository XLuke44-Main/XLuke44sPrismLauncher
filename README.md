# XLuke44's PrismLauncher

This project is my own fork of PrismLauncher 8.4. I originally made it for personal use, but decided to make it publicly accessible as well.

The changes I've made are as follows:

1. **Offline launch is now the default.** For anyone who prefers playing without an internet connection, this should make things a little more convenient.
2. **New Green AMOLED theme was added** and is set as the default theme.
3. **Updates and the news blog have been removed.**
4. **British English is now the default language.** I've also removed the language checks.
5. **Linux is currently the only supported platform for compilation.**
6. **Some menus have been simplified.** For example, the Help menu contained links to the original project, which aren't particularly useful for this fork, as those resources don't necessarily apply here. So... yeah.

One more thing: this fork uses my own custom Java compilation path, which is currently hardcoded. You'll need to change it manually to match your setup.

Anyway, enjoy everyone ^w^ Have a great day/night!
